02 — Projeto extensionista

Tecnologia com propósito

Atividade Extensionista — UNINTER

Capacitação e empregos para comunidades vulneráveis através da tecnologia

O projeto teve como proposta desenvolver uma aplicação simples e acessível para auxiliar jovens na busca por cursos e oportunidades de emprego, utilizando a tecnologia como ferramenta de capacitação e inclusão.

🎯 Objetivo

Desenvolver uma aplicação em Python que facilitasse a busca por cursos e oportunidades de emprego.

💻 Desenvolvimento

Criação de uma interface de usuário simplificada, buscando tornar a aplicação acessível ao público-alvo.

🌱 Impacto

Utilizar a tecnologia como apoio para jovens em busca de capacitação e inserção no mercado de trabalho.

Considerações sobre o projeto

A aplicação foi pensada para ser simples e acessível para jovens que buscam novas oportunidades. Durante o desenvolvimento, um dos principais desafios foi transformar a ideia inicial em uma solução concreta. A criação da identidade visual ajudou a definir melhor a proposta do software e sua finalidade.
